# MALLEUS — Oficio

Prototipo de acción RPG (cámara cenital) del mismo mundo que MALLEUS.

## Cómo jugar

1. Descargá el repo (hace falta la carpeta `assets` junto a estos archivos).
2. Abrí `index.html` en el navegador. No abras `game.js` solo.

**Controles:** WASD mover · clic izquierdo martillo · clic derecho linterna/ballesta · rueda cambia objeto · clic cerca habla / abre.

**Ruta:** plaza → bosque (cofre) → capilla (linterna en el altar) → cripta → volvé al pozo y sellalo.

## Archivos

- `index.html` — ventana
- `game.js` — motor
- `assets/` — fondos, sprites y capas
